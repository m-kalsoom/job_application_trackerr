# Job Application Tracker

A full-stack web application for managing and tracking job applications in one place.

The application allows users to add, update, delete, and organize job applications based on their current application status. 
It includes authentication,a Kanban board, MongoDB database integration, and a responsive user interface.

## Features

-  User authentication with Better Auth
-  Create and manage job applications
-  Edit existing applications
-  Delete job applications
-  Kanban board for tracking application status
-  Drag-and-drop application management
-  Organize applications by status
-  Dark mode support
-  Responsive user interface
-  MongoDB database integration
-  Form validation and error handling
